# Sunrise & Sunset Dashboard – Lab 6 (ITMD 541)

## Description
This responsive web dashboard fetches and displays **sunrise, sunset, dawn, dusk, solar noon, day length, and time zone** data for both **today and tomorrow** using the [sunrisesunset.io API](https://sunrisesunset.io/api/). It supports:
- Location selection (10+ predefined cities)
- Geolocation (current location via browser)
- Responsive design for mobile and desktop

## Features
- Clean UI using Flexbox/Grid
- Fully responsive via media queries
- Error handling with fallback messages
- External CSS and JS files
- API credit included

## How to Run
1. Open `index.html` in a browser
2. Select a location or click "Use My Current Location"
3. View sunrise/sunset details for today and tomorrow

## API Credit
Data powered by [sunrisesunset.io](https://sunrisesunset.io/api/)

## Files Included
- `index.html` – Main HTML structure
- `style.css` – External CSS styling
- `script.js` – JavaScript for fetching and displaying data
